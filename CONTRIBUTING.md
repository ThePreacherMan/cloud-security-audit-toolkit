# Contributing to Cloud Security Audit Toolkit

Thank you for your interest in contributing to the Cloud Security Audit Toolkit.

This project welcomes improvements that strengthen cloud-security checks, reporting, documentation, testing, usability, and provider support.

## Ways to Contribute

You can contribute by:

- Adding new cloud-security checks
- Improving existing detection logic
- Adding AWS, Azure, or Google Cloud resource support
- Improving remediation guidance
- Adding compliance mappings
- Expanding automated tests
- Improving documentation
- Fixing bugs
- Suggesting new features
- Improving report formats
